# AI Resume & Job Description Analyzer

An open-source tool that compares a resume with a job description and identifies matching and potentially missing keywords.

## Features

- ATS-style keyword matching
- Resume and job description comparison
- Match percentage
- Matching keyword identification
- Potentially missing keyword identification
- Basic resume improvement suggestions

## Purpose

This project aims to help students and job seekers understand how closely their resumes align with specific job descriptions and identify areas that may need improvement.

## How It Works

The application analyzes the words used in the resume and job description, calculates a keyword match percentage, and highlights matching and potentially missing terms.
